## 1. 答辩陈述的段落骨架

### 1.1 三个粒度的骨架证据

**粒度 A：90 秒微缩陈述（视频硬字幕）【一手】**——`灵眸智检_90秒展示视频_字幕转录.md`。顺序为：宏大产业背景（2 句）→ 引入主角+比喻定位（"设备'神经脉络'"）→ 单一市场增速（"需求年增20%"）→ 反转痛点（"却被质检牢牢卡住了节奏！"）→ 痛点三连击（人工目检效率低/漏检/机器视觉"接不住"+环境干扰）→ 隐喻收束痛点（"制造业升级的'拦路虎'"）→ 信用背书一句（专利+软著）→ 命名式方案（"硬件+软件+AI"三层架构，每层一个动词分工）→ 极限指标（"毫秒级完成全流程检测"）→ 实物演示转场 → 三层递进升华（企业降不良率→工人转高价值岗位→国家产业链自主可控）→ "答卷"意象收尾。

**粒度 B：书面方案摘要（≈纸面版 3 分钟陈述）【二手-书面方案】**——退化土壤国银《摘要》七步（全文见精选段落文件第一节）：领袖语录/国家战略 → 体量数据（55亿亩）→ 市场规模（千亿级）→ 现有技术痛点 → 命题企业与硬指标 → 团队方案四点（编号+每点八字小标题）→ 成果数据+企业认可+经济社会价值收尾。

**粒度 C：答辩 PPT 页序（48-53 页完整版）【一手】**——见 `sources/articles/获奖队伍PPT_页级骨架图.md`。抽象化后的陈述动线：

```
封面(团队名+口号) → 命题/背景原文复述 → 命题企业认可 → 政策与市场规模 → 痛点(带量化损失)
→ 解题目标(一句愿景) → 研发历程时间线 → 方案总览(命名式框架) → 分方案×N(每页功能+技术+指标)
→ 核心产品展示 → 核心优势×3 → 知识产权 → 竞品对比表 → 客户/需求 → 模式创新 → 盈利模式
→ 推广渠道 → 精品案例×2 → 推广总量数据 → 媒体/领导/院士认可 → 社会价值 → 团队×3-4 → 财务/融资
→ 带动就业 → 教育维度×2-5 → 项目进展 → 与命题方合作规划 → 未来规划 → 尾页口号 → (附录证书备份10-13页)
```

### 1.2 开场 30 秒怎么讲

- 命题类赛道（产业命题）【一手】：开场第一页不是自我介绍，而是**原样复述命题**——把命题背景、命题内容、答题要求三段抄上 PPT（AI农业第2页、甘蔗第3页），口头上一句话点题："我们针对命题企业提出的××问题，提出了××方案"。第二拍就给"解题思路"页（痛点→技术→模式一张图）。
- 通用双创陈述【一手-视频】：用"大背景两句 → 主角对象+比喻 → 一个增速数字 → '却被××卡住了节奏'"的急转句式完成 30 秒破题；比喻定位（神经脉络/拦路虎）是固定修辞动作。
- 大创结题（学术型）【二手-官方通知】：新华国际商学院（东北大学）答辩经验转述为"围绕研究背景、目的、方法、主要内容、结论陈述"——学术型开场是"背景一句话+研究问题"，不搞商业路演式钩子。
- 书面方案的纸面开场【二手-书面方案】：两份国银 md 的第一章/摘要都以**最高级政策话语**起笔（"粮食安全是'国之大者'"／"数字经济为乡村振兴注入新动能"），这是"国赛体"开场的通用起手式。

### 1.3 主体分几大块

- 命题赛道获奖 deck 的主体=**评分维度直接变成章节**：页顶固定导航栏（退化土壤：命题解析/解题方案/实现维度/技术基础/答题团队/教育维度/社会效益；甘蔗：命题解析/创新维度/团队维度/实现维度/教育维度/未来展望）【一手】。每一页让评委随时知道"现在在哪个评分维度上"。
- 方案总览页一律用**命名式框架**打包："1+6+N"模式、"1个库+3个体系"、四大技术体系、"测土配剂+个性化配方+个性化生产+服务"【一手】。口头陈述对应句式："我们把解决方案概括为'1+3'……"
- 技术分述页固定三要素：核心功能 + 关键技术 + 精度/成本指标，一页一技术。
- 大创结题型【二手-官方通知汇总】：主体按"进展→成果→经费使用→训练收获"四块（山东大学经济学院通知原文要点），比商业路演少市场/财务块、多经费与收获块。

### 1.4 收尾怎么收

- 收尾三段式【一手】：①未来规划（短/中/长期三档，或与命题方三阶段合作 2023-2026/2026-2027/2027-2028）；②升华句（从企业价值→行业价值→国家战略递进）；③尾页口号+致谢（"未来在全球范围内推广技术产品，引领农业产业数字化发展！"／"交出青年助力产业链自主可控的答卷！"）。
- 大创结题版收尾【二手-官方通知】：西安交大要求 **PPT 最后两页固定为"资金使用情况"+"大创项目展板图片"**——结题答辩的收尾是"经费+展板"，不是愿景升华。两套收尾不可混用。

规律【推断】：校级/中期 3-5 分钟，国家级结题 5-10 分钟；层级越高陈述越长、问答越充分。**常见陈述档位即 3 / 5 / 8 / 10 分钟四档**。

### 2.2 命题赛道 PPT 的页数配比【一手统计+推断命名】

正式陈述部分（去掉附录）约 38-40 页：命题解析约 18%、解题方案约 28%、技术基础约 13%、实效案例约 12%、团队约 10%、教育/社会约 11%、财务与未来约 7%。若对应 8-10 分钟陈述，**解决方案块约占全时长 1/4 到 1/3，实效案例+数据页约占 1/5**——"方案"与"证据"之比约为 3:2。【推断：由页数配比映射时长，无逐秒实录】

### 2.3 各档切片模板【推断，依据 2.1 时长 + 2.2 配比 + 1.1 骨架】

- **3 分钟（≈900 字，6-10 页）**：钩子+定位 30s → 痛点量化 30s → 方案框架一句话 40s → 核心技术/产品 40s → 成果数据串 40s → 升华收尾 20s。
- **5 分钟**：3 分钟版扩容：分方案 2 页各 30s，加案例 1 页 40s、团队 1 页 20s。
- **8 分钟（主赛道/命题赛道常用）**：再加竞品对比、盈利模式、教育/社会维度；案例给到 2 个。
- **10 分钟（广美式国省级结题/命题决赛）**：全模块走完，最后必须留经费/合作规划收尾；配套附录页备查不宣读。
- 华工路演培训（国创赛语境）强调"**一个项目是否有潜力，三分钟的路演就能看出端倪**"【二手-经验总结】，即开场 3 分钟必须完成"讲清楚做什么/为谁做/为何你做"。

## 3. 数据/图表在陈述中的呈现句式【一手例句，详见 articles 精选段落】

1. **覆盖面三连**："建立示范基地 20 个……近三年累积推广 327.6 万亩，节本增效 6.8 亿元。"（AI农业 PPT28/md1.3.1）
2. **相对提升排比**："节水 20%-25%，节肥 15%-18%，降低农药投入 20%以上，节约劳动力 50%以上，增产 8%-10%。"（同上）
3. **对比基准句**："与矿源腐植酸产品相比：纯度提高≥40%，成本降低 80%。"（退化土壤 PPT25）；"本生产线单套设备规模提高 5 倍以上，能耗降低一半以上……用量降低 50%以上，成本降低 80%以上。"（PPT17）
4. **以命题要求为标尺的对比表**：表首行"命题要求"，中列竞品（含公司名与价格），末行本技术，结论行"优于命题要求/达到企业命题要求"（退化土壤 PPT18-19）。这是命题类答辩最锋利的一页。
5. **每亩账目明细**：节约（劳动力42.5+灌溉33.5+肥料31+农药25.3=132.3元/亩）− 新增投入（108.75元/亩）= 每亩新增效益 208.87 元，再乘推广面积=累计增收（AI农业 PPT28）。
6. **精度三件套**："精度≥89%，误差≤5%，提前 5-6 天预警"——精度、误差、提前量并报（AI农业 PPT18/md1.5）。
7. **计数式成果**："授权国际专利 2 项，软件登记 5 项，发表论文 12 篇，其中 SCI 收录 9 篇，EI 收录 2 篇，核心收录 1 篇。"（md1.3.3）
8. **权威背书句**："通过了金涌院士、费维扬院士、孙金声院士等专家主持的系列鉴定或验收，达到国际领先水平"；"国际通标公司 SGS 测定"；查新："未见国内有相同的研究内容及相同研究成果的报道"。
9. **来源标注**："数据来源：国家统计局""中商产业研究院、前瞻产业研究院"——图表必注来源（甘蔗 PPT6/8）。
10. **数字进标题**：页标题本身携带结论数字："财务预测 2024年成立公司，2027年总营收达到9150万元"（AI农业 PPT37）、"推广应用 建立示范基地20个，近三年累积推广327.6万亩，节本增效6.8亿元"（PPT28）——**结论句标题**，评委扫一眼即得结论【一手】。

## 4. 创新点表述句式【二手-书面方案，原文见 articles 第二节】

- 公式：`首创/首次/率先 + 具体技术动作 + 消除了现有××缺陷 + 破解了××难题`；"填补了国内外××空白"用于具体技术点。
- 每个创新点后必跟**验证链**："实验室 5kg/h 热态小试 → 3000 吨/年中试 → 2 万吨/年示范装置 → 20 万吨/年工业化装置"。
- 层级词序列："国内独创→行业领先→国际领先"（AI农业 PPT31 把三档并列展示，各配鉴定方）。
- 大创（学术型）语境下的对应物【推断】：用"首次将××方法引入××场景""提出了××模型/框架"+ 查新/论文支撑，弱化商业化措辞。

## 5. 收尾与升华句式【一手】

- 三层递进："它不仅能帮企业降不良率、让工人从重复目检转向高价值岗位，更在用创新为中国电子制造业提效降本，交出青年助力产业链自主可控的答卷！"（灵眸智检视频）
- 战略挂钩清单式（退化土壤 PPT37）：保障粮食安全/保护人民健康/农民增产增收/美丽乡村/双碳目标——五格排比。
- 尾页口号式："致力成为智慧农业行业的××"（AI农业封面副口号在 PPT4 重复出现）。

## 6. 高分与普通陈述的结构差异（证据有限，按可信度列）

- 【一手-观察】获奖 deck 的三个共性：①章节=评分维度（导航栏）；②结论句标题带数字；③对比表以"命题要求"为标尺。普通学生 deck 是否缺这些，无对照样本（未找到落选/普通 deck），此差异的"区分度"属【推断】。
- 【二手-经验总结】华工路演培训："讲清楚'做什么''为谁做''为何你做'远比技术本身更重要"；OH 结构（Objective-Highlight）、5W 模型；四大亮点="立项有必要、创新有需要、准备有资源、行动有成果"；BP 一页一重点、数据图示化。（www2.scut.edu.cn/mcsy/2025/1107/c31261a608226/page.htm，注意该文"国创赛"指中国国际大学生创新大赛）
